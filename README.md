# Hospital Management System

## Project Overview
The Hospital Management System is a web-based application developed to simplify hospital operations and manage hospital records efficiently. It provides a centralised platform for managing patients, doctors, appointments, medical records, medicines, rooms, beds, billing, and staff information.

## Technologies Used
- **Programming Language:** Python
- **Framework:** Flask
- **Database:** MySQL
- **Frontend:** HTML, CSS
- **IDE:** Visual Studio Code

## Key Features
- Administrator Login and Dashboard
- Patient Management
- Doctor Management
- Appointment Management
- Medical Records Management
- Medicine and Prescription Management
- Room and Bed Management
- Billing and Payment Management
- Staff Management
- Smart Patient Queue Management

## Smart Patient Queue
The system generates patient token numbers, supports emergency priority, and displays estimated waiting time.

## Installation and Setup
1. Download and extract the project ZIP file.
2. Install the required Python libraries using `pip install -r requirements.txt`.
3. Configure the MySQL database credentials.
4. Import the database using the provided `schema.sql` file.
5. Run the application using `python app.py`.
6. Open the displayed local URL in a web browser.
